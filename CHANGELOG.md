# Changelog

## 1.0.0

First public release for Windows x64.

- Open or drop audio and trim using waveform handles or exact time inputs.
- Preview the selection before saving.
- Export MP3, WAV, FLAC, M4A, OGG and OPUS.
- Replace the original safely while retaining the loaded editing reference.
- Switch between Spanish and English without losing selection or playback.
- Customize application text through a single JSON catalog.
- Portable distribution with Electron and FFmpeg included.
